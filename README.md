Greek Mythology Image Guesser

A fun and interactive game where players guess the identity of an Olympian from a blurred image. The image progressively becomes clearer with correct guesses!

🎯 Features

Interactive Gameplay: Players input their guesses and receive immediate feedback.

Progressive Image Reveal: Images start blurred and become clearer upon correct answers.

Multiple Rounds: Play multiple rounds with different Olympians.

Responsive Design: Works on various screen sizes.

🛠 Technologies Used

HTML

CSS

JavaScript

🚀 Getting Started

Follow these steps to run the project locally:

Prerequisites

A web browser (Chrome, Firefox, Edge, etc.)

Installation

Clone the repository:

git clone https://github.com/cajonathan1/Guess-the-Olypmian.git

Navigate to the project directory:

cd Guess-the-Olypmian

Open the `` file in a browser.

📜 How to Play

A blurred image of an Olympian appears.

Enter your guess in the text input box.

Click the Submit button.

If correct, the image becomes clearer, and you proceed to the next round.

If incorrect, try again!

Play multiple rounds and improve your Greek mythology knowledge!
